# Romantic Date Planner 💖

A premium, mobile-first web application designed to help you plan the perfect romantic date. Built with a beautiful pastel pink aesthetic, glassmorphism UI elements, cinematic transitions, and interactive activity cards.

## Features ✨
- **Mobile-First Responsive Design:** Optimized for smartphones while scaling elegantly to desktop.
- **Glassmorphism Aesthetic:** Soft gradients and frosted glass UI panels.
- **Cinematic Transitions:** Smooth fade-in and slide-up animations between application steps.
- **Background Animations:** Falling/floating hearts and sparkles (with auto-cleanup).
- **Interactive Vibe Selection:** Selectable, animated cards for date activities.
- **Clipboard Integration:** Easy "Copy Plan" functionality using the modern Clipboard API (with legacy browser fallbacks).
- **Form Validation & Accessibility:** Input validation alerts, ARIA attributes, semantic HTML, and respect for `prefers-reduced-motion`.
- **Zero Dependencies:** Built entirely with pure HTML5, CSS3, and Vanilla JavaScript. No backend required.

## Tech Stack 🛠️
- HTML5
- CSS3 (Variables, Flexbox, Grid, Keyframes)
- JavaScript (ES6+)

## How to Run Locally 💻

1. **Download or Clone the Repository:**
   Save all the files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder on your computer named `date-planner`.
2. **Open the Project:**
   Since this project uses vanilla frontend technologies and no external assets that cause CORS issues, you do not strictly need a local development server.
3. **Launch in Browser:**
   Simply double-click the `index.html` file, or right-click and open it with your preferred web browser (Chrome, Firefox, Safari, Edge).
   *Optional:* For a better developer experience, use a live server extension in VS Code.

## How to Publish with GitHub Pages 🚀

GitHub Pages allows you to host this website for free.

1. **Create a GitHub Account:** If you don't have one, sign up at [github.com](https://github.com/).
2. **Create a New Repository:**
   - Click the "+" icon in the top right corner and select "New repository".
   - Name it `date-planner` (or anything you like).
   - Ensure it is set to "Public".
   - Do NOT initialize with a README (since you already have these files). Click "Create repository".
3. **Upload Your Files:**
   - On the repository page, click the "uploading an existing file" link.
   - Drag and drop your `index.html`, `style.css`, `script.js`, and `README.md` files into the browser.
   - Click "Commit changes".
4. **Enable GitHub Pages:**
   - Navigate to the "Settings" tab of your repository.
   - On the left sidebar, click on "Pages" (under the Code and automation section).
   - Under "Build and deployment", set the Source to "Deploy from a branch".
   - Under "Branch", select `main` (or `master`) from the dropdown, leave the folder as `/ (root)`, and click "Save".
5. **View Your Website:**
   - Wait a minute or two for GitHub to build the site.
   - Refresh the "Pages" settings page. You will see a message at the top saying: "Your site is live at `https://[your-username].github.io/date-planner/`".
   - Click the link and share it with your partner!
